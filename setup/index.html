Wi-Fi
프린터 연결
계정 로그인은 PC에서 scripts/setup-server.py를 실행해 이용하세요. 보드의 Wi-Fi 설정 화면에서는 LAN 또는 Cloud 토큰 입력을 사용할 수 있습니다.
비밀번호가 설정된 Bambu Lab 계정이 필요합니다. 비밀번호 없는 소셜 로그인은 지원하지 않습니다.

로그인 후 연결된 프린터를 불러옵니다. 계정 비밀번호는 보드에 저장하지 않습니다.

LAN 모드의 프린터 화면에 표시된 IP와 8자리 access code를 입력하세요.
기존 연결 정보를 재사용할 때만 입력합니다. JWT 토큰이면 사용자명을 비워도 됩니다.

저장 후에는 PC 없이 프린터에 연결됩니다.
